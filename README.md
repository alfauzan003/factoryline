# FactoryLine

Production line simulator → OPC-UA → EIF-style bridge → mini-MES with a live dashboard.
Backend engineering story from the manufacturing world, in C# / .NET 8.

## Tech stack

- C# / .NET 8
- ASP.NET Core
- SQL Server
- OPC-UA (OPC Foundation stack)
- Blazor Server (real-time dashboard)
